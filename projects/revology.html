Revology — The Ideal Revision Website

During my GCSEs I kept running into the same problem: plenty of great resources existed, but never in one place. Revology is a Django platform where students build a shared library of notes and flashcards instead of starting from scratch every exam season.

Research first, then the database

Before writing any code I surveyed 78 students from Years 7–12. 83% weren't completely sure how to revise, 65% made their own notes, and 58% said finding pre-made notes "requires a bit of digging". The sample came from one academically competitive independent school, so if anything the national picture is probably worse. I then mapped every table with its keys — Users, Notes, Flashcard Sets, Flashcards and an Activity table — which translated almost directly into Django models:

supernova/models.py
from django.db import models
from django.contrib.auth.models import User

class Notes(models.Model):
    notes_content = models.TextField()
    author = models.ForeignKey(User, on_delete=models.CASCADE, related_name='authored_notes')
    subject = models.ForeignKey(Subject, on_delete=models.CASCADE)
    title = models.CharField(max_length=30)
    date_uploaded = models.DateTimeField('date uploaded', auto_now_add=True)
    image = models.ImageField(null=True, blank=True)

    def __str__(self):
        return f'{self.id}: {self.title} ({self.subject})'


class Flashcard(models.Model):
    front_of_card = models.TextField(max_length=2000)
    back_of_card = models.TextField(max_length=2000)
    flashcard_set = models.ForeignKey(Flashcard_set, on_delete=models.CASCADE, related_name='flashcards')

    def get_rag(self, user):
        # returns red/amber/green confidence rating for this user
        try:
            return Flashcard_rating.objects.filter(flashcard=self, user=user)[0].status.colour
        except IndexError:
            return Status.red

Two of the eight models in supernova/models.py — with the RAG (red/amber/green) rating logic behind the flashcard filtering feature.

Ethics, beta feedback and what I learned

Because the site collects user data, sign-up only asks for the essentials and all credential handling is delegated to Django's built-in authentication, with user content covered by UK GDPR.

"It's really useful to divide Revology notes and community notes because I know I can trust what I'm reading."

Another beta user suggested past paper questions by topic — a strong idea for version 2, alongside streaks and leaderboards in the spirit of Duolingo. Technically I learned Django properly, across four languages, deployed on PythonAnywhere via a Linux console. The real takeaway was the rhythm of development itself: write, debug, test, repeat, for months.
